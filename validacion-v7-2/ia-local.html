Només dades fictícies. Aquest pont no llegeix el calendari, els PI, els alumnes, els fitxers ni el navegador. No es connecta a cap servidor ni a Ollama directament. La transferència requereix descarregar manualment un JSON i passar-lo a QS33DS Local.

1. Preparar una petició de prova

2. Processar amb QS33DS Local

A QS33DS Local, obre Herramientas → Procesar petición del portal. Selecciona el JSON descarregat i desa el resultat en un fitxer nou.

També pots usar el processador independent amb Python 3.12, sense instal·lar dependències:

Descarrega portal_bridge.py

python portal_bridge.py qs33ds_peticio_demo.json --output resultat.json

El resum funciona sense Ollama. Opcional: afegeix --ollama per usar qwen3:1.7b a 127.0.0.1. El processador no obre ni modifica les bases de dades locals.

Mantén aquesta pestanya oberta fins a carregar la resposta. Si la recarregues o neteges la pantalla, genera una petició nova.
